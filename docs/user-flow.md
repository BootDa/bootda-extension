# 사용자 흐름

1. 사람인 상세 공고 페이지에서 붙다의 `잡플래닛 기업 확인`을 누른다. 기업명, 공고명, 마감일, 공고 ID, 정규화 URL과 필요한 본문 텍스트를 읽는다.
2. 기업명으로 잡플래닛 검색 탭을 연다. 검색 결과 또는 상세 화면에서 `이 회사가 맞나요?`를 표시한다. 동명 기업은 사용자가 확인하며 다른 기업 선택, 검색어 수정, 기업 없음/건너뛰기를 지원한다.
3. 사용자가 기업을 확정하면 허용된 범위에서 평점과 리뷰 수를 읽고 원래 공고 탭에 전달한다. 수집 불가 시 수동 입력 또는 미확인 상태를 지원한다. 리뷰 본문은 저장하지 않는다.
4. 원래 공고 탭으로 복귀한다. 사용자가 기술스택 분석을 요청하면 LLM 결과를 보여준다. 실패 또는 이미지 공고는 직접 수정/건너뛰기 가능하다.
5. `지원예정목록에 추가`에서 기본 정보, 평점, 리뷰 수, 기술스택, 사용자 특이사항을 확인하고 저장한다. 첫 저장이면 Google 계정 권한 승인 및 전용 시트 생성 절차를 제공한다.
6. 성공 시 시트 열기 링크와 저장 완료 표시. 실패 시 데이터를 유지하고 재시도 가능하도록 한다. 중복이면 이미 저장된 공고임을 표시한다.

상태: idle → posting-ready → lookup-pending → company-confirmed/lookup-skipped → review-ready → saving → saved/error. 기술 분석 상태는 별도로 관리한다. 원래 탭이 닫히거나 공고 ID가 바뀌면 다른 공고에 결과를 붙이지 않는다.
