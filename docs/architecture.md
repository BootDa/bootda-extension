# 아키텍처

## 기본 결정

단일 저장소, 분리 배포: `extension/`은 Chrome Web Store용 정적 번들, `api/`는 Vercel 등 서버 측 LLM API 후보. 초기 단계에는 별도 데이터베이스를 도입하지 않는다. Vercel 함수만으로 충분한지 먼저 확인하고 웹 프레임워크 도입은 필요할 때 결정한다.

## 책임 분리

- Content script: 사용자 요청에 따라 현재 공고 DOM에서 기본 정보/공고 텍스트 추출, Shadow DOM UI. 잡플래닛 화면의 허용된 정보 읽기 및 기업 확인 UI.
- Service worker: 메시지 검증, 원본 탭/검색 탭/공고 ID/요청 ID 연계, 상태 전이, 외부 API 호출, 중복 저장 방지.
- Popup: Google 연결/해제, 전용 시트 열기, 현재 진행 상태 확인.
- Google Sheets: 최종 지원예정 기록의 원본 저장소. 생성한 파일 ID와 Google 계정의 연결 관계만 확장 로컬 저장소에 보관. `chrome.identity`를 이용한 최소 범위 OAuth를 실제로 검증하고, 계정 변경/권한 철회/토큰 만료를 처리한다. 토큰은 자체 저장소에 장기 저장하지 않는다.
- LLM API: 사용자가 분석을 요청한 공고 텍스트만 수신. 구조화된 기술 이름 목록 반환. 서버 환경변수에 비밀값 보관. 길이 제한, 엄격한 응답 검증, 타임아웃, 제한된 재시도, 비용 상한 및 공유 가능한 rate limit 검증. IP 제한만으로 충분하다고 가정하지 않는다. 캐시에는 필요 최소한의 해시/결과만 저장하며 보존 정책을 명시한다. 공개 비용 발생 API는 남용 대응 검증 전 운영 배포 금지.

## 세션 및 데이터

`chrome.storage.session`에 `requestId`, `postingKey`, `originTabId`, `lookupTabId`, 현재 단계와 확인 결과를 보관한다. content script에서 직접 읽지 않고 메시지 검증 후 필요한 데이터만 반환한다. 서비스 워커 재시작 후에도 진행 상태를 복원하고, 세션 만료 및 탭 종료를 처리한다. 브라우저 재시작 후 임시 기록 복원이 되지 않음을 안내한다.

공고 키: `saramin:<rec_idx>` (검증된 공고 ID만 사용). 출처와 URL을 검증하고 추적용 파라미터는 저장하지 않는다. ID 확인 불가 시 저장 전 사용자에게 오류를 알린다. 회사 연결은 별도로 사용자가 선택한 잡플래닛 기업 ID로 관리한다.

## 스프레드시트

최초 저장 시 사용자가 Google 권한을 승인하면 `붙다 - 지원예정목록` 파일을 생성하고 다음 저장부터 동일 계정의 파일을 재사용한다.

| 열 | 의미 |
|---|---|
| 저장일 | 최초 저장 시각 |
| 플랫폼 | 사람인 |
| 기업명 | 공고상 기업명 |
| 공고명 | 제목 |
| 마감일 | 날짜 또는 상시채용 등 원문 |
| 기술스택 | 확인한 기술 이름 |
| 잡플래닛 기업명 | 사용자 확인 기업 |
| 잡플래닛 URL | 기업 페이지 |
| 평점 | 0~5 또는 미확인 |
| 리뷰 수 | 0 이상 정수 또는 미확인 |
| 특이사항 | 사용자 메모 |
| 지원 상태 | 지원 예정 (초기값) |
| 원문 URL | 검증된 공고 링크 |
| 공고 ID | 중복 확인 키 |

사용자 확인 후 `RAW` 값으로 기록한다. 공고 ID 중복 확인, 계정/파일별 직렬화, 이중 클릭 잠금, 결과가 불확실한 요청의 재조회 후 재시도 적용. Sheets에는 고유키 제약이 없으므로 여러 기기 동시 저장 시 중복이 완전히 방지되지는 않는다. 기존 사용자 편집값은 자동 덮어쓰지 않는다. 파일 삭제 및 열 구조 변경 시 복구 안내를 표시한다.

## 권한

사람인 미리보기는 `activeTab`과 `scripting` 권한으로 사용자가 확장 팝업에서 요청한 현재 탭의 상세 화면을 읽는다. 사이트 상시 접근 권한은 사용하지 않는다. 후속 기능에서 필요한 권한만 추가한다.

## LLM 인터페이스 초안

POST `/api/analyze-tech-stack` 입력: `{ text: string }`. 응답: `{ skills: string[] }`. 명시된 기술만 포함, 중복 제거, 근거가 없으면 빈 배열. 이미지 기반 공고는 미지원으로 표시하고 직접 입력 가능. 모델 공급자/키/요청 상한은 후속 단계에서 확정한다.
