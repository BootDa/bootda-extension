# Extension release notes

## 0.3.2 — 사람인 무한스크롤 대응 (미출시)

- 추천 공고로 스크롤하면 붙다 버튼과 툴바 팝업이 현재 공고를 기준으로 동작합니다.
- 다른 공고로 넘어가면 기존 미리보기를 닫고, 같은 공고의 기본·고정 헤더 사이에서는 유지합니다.

## 0.3.1 — 고정 헤더 전환 보완 (미출시)

- 고정 헤더가 현재 공고와 일치할 때 붙다 버튼을 옮깁니다.
- 스크롤만 할 때는 열린 미리보기의 공고 본문을 다시 읽지 않습니다.

## 0.3.0 — 사람인 상세 정보 및 미리보기 갱신 (미출시)

- 사람인 공고의 경력, 급여, 학력, 근무일시, 근무형태, 근무지역, 우대사항과 읽을 수 있는 텍스트 본문을 페이지 내 미리보기에 표시합니다.
- 주소와 일치하는 상세 영역이 열릴 때까지 이전 공고를 숨기고, 늦게 표시된 마감일은 열린 미리보기에 반영합니다.

## 0.2.3 — 스크롤 중 공고 미리보기 유지 (미출시)

- 붙다 버튼이 스크롤에 따라 사람인 기본 헤더와 고정 헤더 사이를 이동합니다.
- 같은 공고에서 헤더가 전환돼도 버튼은 하나만 표시되며 열린 미리보기가 유지됩니다.

## 0.2.2 — 사람인 페이지 내 공고 확인 (미출시)

- 입사지원 영역 아래에서 **붙다 · 공고 확인**을 누르면 같은 페이지에 회사명, 공고 제목, 마감일을 표시합니다.
- 마감일이 없으면 미확인으로 표시하며, 다른 공고로 이동하면 미리보기를 닫습니다.

## 0.2.1 — 사람인 상세 화면에 붙다 버튼 배치 (미출시)

- 사람인 상세 공고의 입사지원 영역 아래에 붙다 버튼을 표시합니다.
- 공고 이동이나 화면 갱신 후에도 버튼을 하나만 표시합니다.
- 이 버전의 페이지 내 버튼은 비활성화되어 있습니다.

## 0.2.0 — 사람인 공고 미리보기 (미출시)

- 사람인 상세 공고에서 회사명, 공고 제목, 마감일을 읽어 팝업에 표시합니다.
- 공고에서 마감일을 확인할 수 없으면 미확인으로 표시합니다.
- 팝업에서 요청한 현재 탭만 읽을 수 있도록 `activeTab`과 `scripting` 권한을 사용합니다.

## 0.1.1 — 확장 빌드 환경 전환 (미출시)

- pnpm으로 의존성을 고정하고 WXT로 Chrome Manifest V3 팝업을 빌드합니다.
- 기존 React 팝업 상태 표시에 Tailwind CSS v4 기반 shadcn/ui Badge를 적용했습니다.
- 빌드에서 생성된 manifest의 버전, 권한 및 팝업 경로를 검증합니다.

## 0.1.0 — 개발용 초기 기반 (미출시)

- React + TypeScript + Vite 팝업 초기 화면.
- Manifest V3 및 공고 식별/기술스택 검증 모델.
- 제품 아키텍처와 단계별 계획 문서.
- 외부 API, 수집 및 저장 기능은 미구현.
