# Extension release notes

## 0.1.1 — 사람인 공고 정보 확인 (미출시)

- 사람인 상세 공고에서 기업명, 제목, 마감일, 공고 ID, 정규화 링크와 본문 텍스트를 읽습니다.
- 페이지 버튼을 누르면 추출 정보를 확인할 수 있습니다. 마감일과 본문 텍스트가 없으면 미확인으로 표시합니다.
- 공고 이동 시 이전 공고 정보 표시를 초기화합니다.

## 0.1.0 — 개발용 초기 기반 (미출시)

- React + TypeScript + Vite 팝업 초기 화면.
- Manifest V3 및 공고 식별/기술스택 검증 모델.
- 제품 아키텍처와 단계별 계획 문서.
- 외부 API, 수집 및 저장 기능은 미구현.
